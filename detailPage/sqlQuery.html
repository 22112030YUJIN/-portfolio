SQL 쿼리 시각화 IDE

이 프로젝트는 SQL 쿼리에 익숙하지 않은 입문자 및 비전공자도 쉽게 사용할 수 있는 시각화 기반의 WEB IDE개발을 목표로 합니다.
기존 텍스트 기반 SQL의 높은 진입장벽을 해소하고, 데이터 활용의 효율성을 극대화하고자 DB 연결 관리, 프로젝트 멤버 초대 및 실시간 알림, 쿼리 작성/저장/공유, 실시간 채팅 등 협업 중심 기능을 제공합니다.
핵심 컨셉은 ERD 기반 시각화 탐색, 시각적 SQL 쿼리 빌더, 그리고 실시간 협업 환경 구축입니다.
사용자 경험 향상을 위해 i18n(국제화)을 적용하여 영어/한국어 다국어 지원이 가능합니다.

주요 기술 스택: React, Vite, Chakra UI, Monaco Editor, Axios 통신: RESTful API, WebSocket

마이페이지: 프로필 및 보안 관리

❮ ❯

사용자의 기본 프로필 관리, 정규화식(대문자, 소문자, 숫자, 특수문자를 포함하는 10자리 이상)을 맞춘 비밀번호 변경, 회원탈퇴 기능을 제공합니다. 또한 프로젝트 수신/발신 목록을 조회하여 협업 관련 알림 상태를 관리합니다.
이 페이지는 JWT 기반의 인증 및 권한 부여 시스템과 연동되어 사용자 계정 보안을 유지하며, 입력 필드에 유효성 검사 로직을 적용하여 데이터 무결성을 확보합니다.

내 기여: 해당 UI/UX 구현, 개인 정보 수정 및 탈퇴, 유효성 검사 로직 설계, 프로젝트 초대 및 거절

대시보드: 프로젝트 관리 및 실시간 협업

❮ ❯

프로젝트의 생성, 수정, 삭제 및 DB 초기 연결을 관리하고 각 프로젝트별 IDE 편집을 위한 전체 내역을 보여줍니다.
프로젝트 멤버 초대 기능을 구현하여 이메일을 통한 멤버 초대가 가능하며, 초대 시 상대방에게 실시간 알람이 전송됩니다.
사용자는 알람 목록에서 초대를 수락/거절할 수 있으며, 수락 시 프로젝트 멤버로 즉시 반영됩니다.
OWNER와 MEMBER 역할 구분을 통한 접근 권한 제한이 시각적으로 표시됩니다.

내 기여: UI구현 일부 도움 및 수정, 프로젝트 멤버 초대/수락/거절 기능 UI 및 실시간 알람 연동 로직 구현, 최근 프로젝트 열람 기능 구현

DB 연결 관리: 스키마 및 권한 시각화

❮ ❯

DB 연결 상태를 관리하는 페이지로, 이미 연결된 프로젝트는 사용자 권한 및 연결 상태를 UI로 시각적으로 제공합니다.
연결이 안 된 프로젝트는 '새 연결 추가' 모달 창을 통해 MySQL, PostgreSQL 등 다양한 DB와의 연결을 지원하며, 연결 후에는 동적 DB 스키마 시각화 정보를 IDE 사이드바에 표시합니다.

내 기여: 전체 UI/UX구현, DB 미 연결 프로젝트 선택 시 DB연결 관리 기능 모달 창 연결

IDE: 시각적 쿼리 빌더 및 코드 편집 환경

❮ ❯

각 프로젝트 별 핵심 작업 공간 IDE입니다. monaco-editor를 통합하여 SQL 구문 하이라이팅 및 자동 완성 등 전문적인 코드 작성 환경을 제공합니다.
이 IDE는 시각적 쿼리 빌더 기능을 통해 DB 스키마 뷰에서 테이블/컬럼을 드래그 앤 드롭하여 SQL 쿼리를 자동으로 생성하며, 쿼리 실행 결과는 표 형태로 렌더링 됩니다. 또한, i18n(국제화)을 적용하여 사용 언어를 쉽게 변경할 수 있습니다.

내 기여: UI/UX 설계 및 IDE 폴더 생성/삭제/이름 수정 등 파일 탐색기 UI 구현, 언어 변경 기능, SQL문 생성

채팅: 실시간 협업 및 커뮤니케이션

❮ ❯

프로젝트 멤버 간의 원활한 소통을 위한 페이지입니다. WebSocket을 활용하여 프로젝트 별 그룹 채팅 및 1:1 채팅방을 제공하며, 좌측 목록에서 각 채팅방 별 최근 대화 내역과 현재 멤버 목록을 확인할 수 있습니다.

내 기여: WebSocket 통신 기반의 채팅 UI/UX 설계 및 구현, 새 프로젝트 채팅방 자동 생성, 프로젝트 내 멤버 자동 친구 추가
